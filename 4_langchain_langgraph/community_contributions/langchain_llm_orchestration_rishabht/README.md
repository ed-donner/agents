# LangChain LLM orchestration (subagent + tools + checkpointer)

Week 4 community contribution: a small `create_agent` example that orchestrates a main agent, tools, structured output and a nested apparel LLM subagent, with `MemorySaver` so follow-up questions keep the city in context.

Run from this directory (with the course venv and `OPENAI_API_KEY` set):

```bash
python llm.py
```

See `Output.md` for a sample run.
