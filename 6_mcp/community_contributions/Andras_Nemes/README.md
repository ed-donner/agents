# Week 6 MCP exercises

- **Day 2 — Build an MCP server:** `Lab2_MCP/push_server.py` exposes a Pushover notification tool. `Lab2_MCP/push_lab.ipynb` discovers the tool and gives it to an agent to send a message.
- **Day 3 — Add a marketplace context source:** `Lab3_FromMarketPlace/lab3_extension.ipynb` connects to a Yahoo Finance MCP server found on Smithery. It combines news and price history with the lab's market-price server to answer a stock-market question.
