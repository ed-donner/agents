# Report-learning prompt chain

A Week 1 Lab 1 extension by [charlie-analytics](https://github.com/charlie-analytics). Open `report_learning.ipynb` in the course Python environment and run all cells for offline replay; no API key or network is needed. An uncalled function marks the optional remote inference boundary.

The three stages use limited researcher-supplied report cards to produce observations, writing principles, and an original outline/opening for a fictional numerical-verification guide. Models saw the complete limited cards, not full PDFs. This is a controlled chain, not a popularity ranking, autonomous research, or a validated publishing tool. Official source links and exact selected prompts/responses are in the notebook.

Ten actual requests reported $0.0015544 total inference cost. Nine free attempts exposed truncation, classifier routing, count failures and confusion between teaching examples and evidence. The paid final-stage comparison used `openai/gpt-4.1-mini`: its useful outline has five allocations totaling 1,200 words, but its raw opening still failed at 75 words. One explicitly labeled local editorial sentence makes 85 words; the raw response remains unchanged. Historical costs do not guarantee future prices.

Notebook outputs are cleared for this contribution. Local replay checks supplied-note/page matches, principle references, allocations and the honest word-count failure/local repair.
