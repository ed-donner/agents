# Digital Twin

Учебный веб-чат, который отвечает на вопросы о профессиональном опыте владельца. Контекст собирается из `summary.txt` и `resume.pdf`, ответы генерируются через OpenRouter, а контактные данные и неизвестные вопросы отправляются владельцу в Telegram.

Если агент не знает ответ, посетитель сразу видит просьбу подождать, а вопрос отправляется владельцу. Владелец отвечает через Reply в Telegram, после чего промежуточное сообщение заменяется ответом агента.

## Требования

- Python 3.10 или новее
- ключ OpenRouter
- Telegram-бот и ID чата для уведомлений

## Установка

```bash
cd 1_foundations/community_contributions/zhodino_byte/twin
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

Заполните в `.env` значения `OPENROUTER_API_KEY`, `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Необязательная настройка `OWNER_REPLY_TIMEOUT_SECONDS` определяет, сколько секунд сайт ждёт ответ владельца; по умолчанию — 120 секунд.

## Запуск

```bash
python app.py
```

Gradio напечатает локальный адрес сайта в терминале. Одновременно приложение запустит получение сообщений Telegram-ботом.

## Структура

- `app.py` — Gradio-интерфейс и цикл общения с моделью.
- `config.py` — загрузка и проверка настроек.
- `context.py` — сбор контекста из резюме и краткого описания.
- `human_bridge.py` — связь между ожидающим запросом сайта и Reply в Telegram.
- `tools.py` — инструменты модели и Telegram-уведомления.
- `user_answer.py` — создание и обработчики Telegram-бота.
- `styles.py` — оформление интерфейса.

## Как ответить посетителю из Telegram

1. Дождитесь сообщения с неизвестным вопросом.
2. Нажмите Reply именно на это сообщение.
3. Отправьте текстовый ответ до завершения времени ожидания.

Обычное сообщение без Reply не связывается с вопросом. После перезапуска приложения ожидающие вопросы теряются — это ограничение учебной версии без базы данных.
