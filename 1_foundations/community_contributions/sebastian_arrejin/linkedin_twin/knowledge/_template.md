# Template for extra knowledge (this file is ignored)

Files whose name starts with "_" are not loaded into the knowledge base.
Copy this file to a new name without the underscore (for example `experience.md`),
replace the examples with real information, and restart the app.
The embeddings are recalculated automatically for new or changed content.

You can also drop PDF files here, such as the LinkedIn "Save to PDF" export or your CV.

Use one "##" heading per topic: each section becomes one searchable chunk.

## Work experience

- Company, role, start date - end date: main responsibilities, projects, achievements.

## Education

- Universidad Siglo 21: degree, years.

## Projects

- Name of the automation framework or project, technologies used, results.

## Languages

- Spanish (native), English (level).

## Frequently asked questions

- Salary expectations, notice period, preferred time zone, etc. Only what you are happy to share publicly.
